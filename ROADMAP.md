# Roadmap

## 0.1.x

- Stabilize core repository hygiene checks.
- Add clearer output for GitHub Actions logs.
- Collect maintainer feedback from early adopters.

## 0.2.x

- Add optional check profiles for common ecosystems.
- Add workflow annotations for failed checks.
- Support configurable privacy patterns.

## Long-Term Direction

Release Sentinel should remain a focused maintainer utility rather than a large compliance suite. The project will favor checks that are explainable, testable, and useful across many public repositories.
