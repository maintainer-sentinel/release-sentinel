# Support

Release Sentinel is maintained through GitHub issues.

## Before Opening an Issue

- Run the latest released version.
- Include the command you ran.
- Include the check output.
- Share only public repository layouts and sanitized examples.

## Good Support Requests

- A check fails with unclear guidance.
- A repository layout should be supported but is not.
- The GitHub Action behaves differently than the CLI.
- Documentation is missing a common maintainer workflow.

## Security Issues

Use `SECURITY.md` for security reports. Do not include exploit details or private repository data in public issues.
