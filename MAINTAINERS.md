# Maintainers

## Primary Maintainer

- `maintainer-sentinel`

## Maintainer Responsibilities

- Review issues and pull requests.
- Keep CI and tests passing.
- Publish release notes for tagged versions.
- Triage security reports.
- Preserve a low-dependency, maintainer-friendly project scope.

## Maintainer Boundaries

Release Sentinel does not collect telemetry, require account linking, or inspect private repository data beyond files available in the checked working tree.
